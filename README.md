# Drum Kit Website

A simple interactive drum kit web app that lets users play drum sounds by clicking buttons or using keys on their keyboard.

## 🔗 Demo

Play the app online: [Drum Kit Website Live Demo](https://abo-ah-md.github.io/Drum_kit_website/)

## 🎹 Features

- Click buttons or press keys (`w`, `a`, `s`, `d`, `j`, `k`, `l`) to play different drum sounds.
- Buttons visually respond when pressed (animation/style changes).
- Real drum sounds mapped to UI buttons.
- Attractive, responsive CSS design.

## 🛠️ Tech Stack

- **HTML** (`index.html`)
- **CSS** (`styles.css`)
- **JavaScript** (`index.js`)

### JS Key Logic

- Adds click event listeners to each drum button.
- Adds keydown event for keyboard input.
- Maps button/keyboard (`w`, `a`, etc.) to different sounds.
- Animates button by changing style and adding a pressed effect.

### Images and Sounds

- All drum images are stored in the `images` folder.
- All sound assets (drum, snare, kick, crash, toms) are stored in `sounds` folder.

## 🚀 How to Run Locally

1. **Clone the repo**:  
   `git clone https://github.com/abo-ah-md/Drum_kit_website.git`
2. Open `index.html` in your browser.
3. Start playing the drum kit by clicking UI buttons or pressing keys!
